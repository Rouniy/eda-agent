# PCB 质量约束

配合 eda-agent 设计流程使用的约束集，管的是成品板的**物理质量下限**：
能不能造出来、能不能装配、能不能调试、能不能被人读懂，以及看上去是工程
师画的还是脚本吐的。

用词约定：**必须** / **禁止** 为硬性；**应当** 允许有据可查的例外；
**可以** 表示许可但不强制。

英文版为准： [rules.en.md](rules.en.md)

---

## 0. 边界：本文不管什么

流程顺序由服务端拥有。`design_next_action` 决定 13 个阶段中哪个该跑、
何时算完；`design_get_discipline` 拥有原理图规划器的规则；
`design_visual_review` 拥有"渲染 → 观察 → 批评"这个回路。**本文不新增
阶段、不改动顺序、不覆盖上述任何一项。**

本文补的是它们都不覆盖的那一层：`rules_stackup` 在合成规则之前必须先
存在的那批数值意图，以及让 `placement`、`routing`、`pours_tuning`、
`outputs` 产出一块能签字放行的板子所需的几何与文档标准。

下面每一节的标题标注了它绑定的阶段。该阶段进行中适用该节规则，
`verification` 阶段再复查一遍。

### 优先级

两条规则冲突时，按此顺序裁决：

1. 安全与可制造性 —— 板子能被制造、装配、上电而不损坏
2. 电气正确性 —— 网表一致、阻抗、回流路径、电源完整性
3. 可维护性 —— 可测试、可返修、可读
4. 视觉质量 —— 对齐、一致、整洁

低优先级不得以牺牲高优先级为代价。但在高优先级不受影响时，**第 4 条是
硬要求而不是锦上添花**：成品板上几乎总有余量，"能布通"不是标准。

## 1. 板级意图 —— 阶段 `requirement`、`architecture`

`design_validate_requirement` 抓的是功能需求，`design_load_fab_profile`
抓的是工厂能力上限。两者之间还夹着一批物理事实，谁都没管，而
`rules_stackup` 没有它们就合成不出正确的规则。

离开 `architecture` 阶段之前填完 `board-intent.template.md`。每一项要么
**由用户给出**，要么**由列出过程的计算得到**。两者皆非的项必须转成
`open_question` 并阻塞该阶段。

| 字段 | 为什么它卡住后续阶段 |
|---|---|
| 板框、原点及其来源 | 没有它 `placement` 无法开始 |
| 安装孔：位置、孔径、禁布半径 | 固定几何必须先放好并锁定 |
| 机壳 / 配合件约束 | 连接器位置不是自由的 |
| 最高工作频率**与**最快边沿 | 决定第 8 节是否生效 |
| 阻抗控制网络、目标阻抗、单端/差分 | 喂给 `pcb_calc_impedance` 与差分规则 |
| 最大电流网络及其电流 | 喂给 `pcb_calc_trace_width_for_current` |
| 工作温度范围 | 降额与散热铜面预算 |
| 装配方式：单面回流 / 双面 / 含手焊件 | 决定底面布局规则 |
| 表面处理 | 影响焊盘处理与细间距工艺 |
| 是否拼板、是否需要工艺边 | 预留板边空间 |
| 测试策略：针床 / 探针点 / 无 | 决定第 6 节的测试点规则 |

**禁止用典型值代替缺失值。**"就按 4 层 1.6 mm FR-4 算"是这套流程里最
昂贵的一句话：后续算出的每一个线宽、间距、阻抗、缝合间距都继承了这个
猜测，而真实叠层到手时没有任何一个会被重算。

工厂能力档本身已经有同样的纪律 —— `FabProfile.source` 这个字段存在，
就是为了让数字能追溯到某个能力页面和某个日期。照做：抄录、标注出处、
绝不凭记忆。

## 2. 先有规则，再有几何 —— 阶段 `rules_stackup`

**在设计规则进入编辑器之前，禁止放置任何走线、过孔或铺铜。** 只活在
对话里的约束几轮之内就会被遗忘；写进设计规则的约束，此后每次
`pcb_run_drc` 都会强制执行。这就是一块能收敛的板和一块要返工重布的板
之间的区别。

优先用 `design_synthesize_rules(profile=...)` —— 它把每个数值都追溯到
能力档字段或经过验证的计算器，并返回可原样下发的
`pcb_create_design_rule` / `pcb_modify_layer` 参数字典。手写规则是例外，
且每个手写数值必须附一行理由。

规则集至少必须覆盖：

- **间距（Clearance）**，按 net class 分档 —— 信号、电源、高压、射频 ——
  而不是一个全局值
- **线宽（Width）**，按 net class，`value`（最小）、`favored_value`
  （布线器默认值）、`max_value` 三者都要填
- **过孔**尺寸由 `min_drill + 2 × min_annular_ring` 推出，不得比能力档
  更激进
- **板边间距**，对所有铜层
- **孔到孔**与**孔到铜**
- **器件间距**，保证装配不干涉
- **丝印到阻焊 / 丝印到焊盘**，不允许位号压到焊盘上
- **阻焊与钢网开窗**，统一；任何逐焊盘的例外都要记录
- **差分对间距与等长**，第 8 节适用时
- **铺铜连接方式** —— 平面与散热焊盘用**直连**，不用花焊盘。在回流装配
  的板子上，地平面用花焊盘只是白白付出电感和热阻。手焊件**可以**用花
  焊盘，但要注明是哪些、为什么。

**永远不要贴着工厂的极限设计。**留一档余量 —— 能力档允许 3.5 mil 线宽
时，除非密度确实不允许，就按 5 mil 画。踩着极限的板良率更差、成本更高，
而且下一版需要加宽某根线时你无处可退。

修改已有规则前必须报告**改什么、为什么、改前 → 改后**。

## 3. 布局 —— 阶段 `placement`

`pcb_plan_placement` 优化 HPWL 并保持分组。下面这些规则约束它被允许产出
什么。

### 3.1 顺序

1. 先放好并**锁定**所有机械上固定的东西：连接器、安装孔、指示器件，
   以及任何由机壳或配合件决定位置的元件。锁定对象此后禁止移动；确需
   移动，先报告再询问。
2. 然后放功能块。
3. 最后放每个功能块内部的元件。

在固定几何锁定之前就优化，产出的布局注定要推倒重来。

### 3.2 电气布局

- 同一功能块的元件**必须**物理聚集。一个元件散落全板的功能块就是缺陷，
  网络长度再短也一样。
- 信号流**应当**沿一个方向横穿板子 —— 输入到输出，左到右或下到上 ——
  不折返。
- 去耦电容**必须**位于它所去耦的引脚处，取可用的最短
  电容 → 引脚 → 过孔 回路。到 IC 的距离是错误的指标；**回路面积**才是
  指标。一个贴得很近但过孔打在远端的电容，比一个稍远但过孔就在焊盘旁
  的电容更差。
- 晶体与振荡器：紧贴其 IC，走线尽可能短，其下方与旁边不走其他信号。
- 敏感模拟 —— ADC 基准、运放输入、高阻节点 —— 远离开关电源、大 di/dt
  回路和连接器。
- 开关电源的热回路（开关节点、输入电容、二极管/MOS）在该块内**最先**
  按最小回路面积摆放。
- 发热器件分散，禁止聚堆；铜面面积与散热过孔在布局阶段就预算好，而不是
  等布线时才发现。
- 连接器朝板边，留出配合件、线缆弯曲半径和一只手能伸进去的空间。

### 3.3 几何 —— 让板子看起来是"设计过的"

- 每个元件原点**必须**落在**唯一声明的布局网格**上（公制 0.5 mm，或英制
  25 mil）。用 `audit_find_off_grid_components` 确认。
  `X = 12.3847 mm` 这样的坐标是缺陷，不是舍入细节。
- 旋转角**必须**是 90° 的整数倍。其他角度需要给出理由 —— 射频匹配结构
  和受机械约束的器件算理由，"布线器更喜欢这样"不算。
- 一组同类元件 —— 电阻阵列、去耦电容组、LED 排、测试点 —— **必须**成行
  或成列对齐，且**间距统一**。是统一，不只是"看着整齐"：每两个之间都是
  2.0 mm，而不是 1.8 / 2.1 / 1.95。
- **极性器件在块内朝向一致**：二极管、电解电容、IC 的 1 脚统一朝向。
  这正是让装配错误一眼可见、让检验变快的东西。
- 间距**必须**在视觉上一致。这里挤那里空，即使电气上没问题，读起来也像
  没画完。
- 让板面的"重量"分布开。功能约束确实导致不对称时，用铺铜和丝印去平衡，
  而不是留一个空白象限。

### 3.4 禁止

- 移动已锁定的对象。
- 为了布线方便把元件推出它所属的功能块。
- **自造封装。** 库里没有就停下来说明。没有拿到数据手册焊盘图就创建的
  封装**必须**标记 `UNVERIFIED` 并列入报告 —— 绝不静默产出。
  `library_readiness` 阶段的存在就是为了拦住这件事，不要绕过它。

## 4. 布线 —— 阶段 `routing`

- **禁止 90° 直角，禁止锐角。** 转角只用 45° 或圆弧。用
  `audit_find_acute_angles` 确认。
- 同一网络线宽恒定。确需改变时用渐变，不得阶跃。
- 并行走线保持统一间距，读起来像一条总线。成组布线，而不是一根一根布完
  再把其余的塞进空隙。
- 相邻层**应当**以正交方向为主。
- 无残桩、无环路、无孤立铜、无锐角铜尖。残桩用
  `audit_find_via_antennas` 确认。
- 尽量少换层：单个信号网络默认 ≤ 2 个过孔，超出需给理由。
- **每根走线下方必须有连续的参考平面。** 禁止跨越平面分割。确实无法避免
  时，在跨越处加跨接电容并报告 —— 否则回流电流要绕远路，那个回路就是
  天线。
- 大电流网络的线宽来自 `pcb_calc_trace_width_for_current`（IPC-2221），
  不来自经验。算出的宽度放不下时，多层并联加过孔阵列 —— 并且说明。
- 敏感模拟不与数字或开关网络长距离并行。必须交叉时正交交叉。
- 差分对：同层、全程等间距、对称走线、同时换层。**在偏斜产生的源头做对
  内等长**，而不是在末端给其中一条绕蛇形。

## 5. 铺铜与接地 —— 阶段 `pours_tuning`

- 保持参考平面**完整**。每一道平面切口都是回流电流的一段绕行。切口不可
  避免时，显式追踪回流路径，确认它没有被迫绕远。
- **铺铜必须在整个面上缝合过孔，而不只是沿走线边缘围一圈。** 走线旁边
  的过孔围栏，会让围栏之间的铜面自由地作为贴片谐振；在薄基材、高频下，
  那块铜面正是块间耦合的结构。用 `pcb_place_stitching_vias` 覆盖铺铜
  区域。
- 缝合间距要推导，不要凭习惯：

  ```
  λ_g = c / (f · √εr)          间距 ≤ λ_g / 20   （严格）
                               间距 ≤ λ_g / 10   （一般）
  ```

  用第 1 节里最高关注频率 —— 数字电路用边沿隐含的带宽
  （`f_knee ≈ 0.35 / t_r`），不是时钟频率。**把代入过程和结果写出来**；
  光给一个 "1.5 mm" 无法审计。
- 每个换参考层的信号过孔旁都要有回流过孔 —— 默认 1.5 mm 以内，第 8 节
  适用时更近。
- 接地焊盘通过就在焊盘上或紧挨焊盘的过孔连到平面。要经过一段走线才到地
  的焊盘，在高频下不叫接地。
- 每次重新铺铜之后：清除孤岛与铜尖，然后**重跑 `pcb_run_drc`**。重新
  铺铜是几何改动，把它当成外观调整，正是干净的板子变脏的方式。

## 6. 丝印与文档 —— 阶段 `placement`、`outputs`

丝印的读者是一个手里拿着烙铁、正拿着这块板的人。按这个标准评判它。

- 全板文字高度与线宽统一。默认字高 0.8–1.0 mm、线宽 0.15 mm；绝不低于
  能力档的 `min_silk_width_mils`。
- **位号旋转只允许 0° 或 90°**，读法为从左到右、从下到上。用
  `audit_find_mirrored_pcb_text` 确认。
- 丝印不压焊盘、过孔、基准点。位号不得对应不清是哪个元件。用
  `audit_find_designator_collisions` 确认。
- 必须标注：**1 脚**、极性、连接器引脚定义，以及任何装配时可能装反的
  方向。
- 板子自带身份：板名、版本号、日期，以及必要的合规标识。
- SMT 装配需要 3 个非对称基准点。
- 测试点：统一封装、落在网格上、集中于一面且可达、有标注，覆盖每一路
  电源和每一个值得探测的信号。与第 1 节声明的测试策略一致。

自检标准：**一个从没见过这块板的人，能不能只靠丝印把它装对？** 不能，
就是没做完。

## 7. 可制造性与可装配性

- 所有几何都落在能力档之内并留有余量（第 2 节）。
- 板边：元件远离板边 —— 默认 5 mm，用工艺边或 V 割时更多。第 1 节声明
  要拼板时预留工艺边宽度。
- 封装遵循 IPC-7351 焊盘图。不要为了塞下某个元件而缩放封装。
- 尽可能**全板统一一种贴片尺寸系列**。无理由地混用 0402 / 0603 / 0805
  会占用飞达位，并且招来"错料装错位"。
- 细间距焊盘之间的阻焊桥必须超过能力档的 `min_mask_sliver_mils`；低于该
  值时，明确说明阻焊如何处理。
- 双面回流：底面只放小型贴片元件，重的、高的放顶面。
- 手焊件周围留出烙铁能以工作角度伸入的空间。
- BOM：每一行都可采购，带真实的厂商料号。按规划器的纪律，优先用库存
  已有的料。

## 8. 高速与射频 —— 条件生效

**满足任一条即生效**：最高频率 > 100 MHz；边沿 < 1 ns；存在任何阻抗控制
网络。只要有一条成立，整节都是强制的。

- 阻抗控制线宽由 `pcb_calc_impedance` 针对真实叠层算出，或取自工厂的阻抗
  表。**凭经验选的线宽不可接受**，推导过程要写进报告。
- 阻抗控制走线全程参考同一个连续平面。换层处参考平面必须保持连续，且换
  层处伴随接地过孔。
- 射频转角用圆弧或斜切 —— 绝不用直角。
- 射频走线旁的净空：≥ 3 倍线宽，净空内无其他铜。
- 端接与匹配元件放在它们起作用的那一点上。
- 功分、合路及任何分支结构：把各支路长度与相位控制在声明的容差内，并把
  该容差写成等长设计规则，让 DRC 去查。
- 走线在元件焊盘处必须改变宽度时，用渐变过渡。
- 屏蔽罩下方：无丝印，封装区内无高器件，罩壁下方有连续缝合的接地环。
- 缝合间距按第 5 节，按最高关注频率计算。

## 9. Agent 行为准则

这几条约束的是**你怎么工作**。它们比技术条款更常被违反，代价也更大。

1. **先读后写。** 修改任何东西之前先确认并报告当前状态。
   `design_review_snapshot` 能把这些读取打成一包。
2. **风险前存档。** 在 `sch_to_pcb`、`routing`、`pours_tuning` 之前，
   以及任何批量编辑之前，先 `app_checkpoint`。
3. **小步走。** 单次操作默认 ≤ 20 个对象；更大范围的改动先说明范围并取得
   确认。
4. **绝不假设参数。** 缺失的输入变成 `open_question` 并阻塞该阶段。
   写下"我就先按 4 层算"这句话本身就是违规。
5. **绝不静默降低标准。** 做不到的约束就报告为未达成。把悄悄的妥协报告
   成"已完成"，是这里最坏的失效模式 —— 因为它是没人会发现的那一种。
6. **改动可追溯。** 每一轮报告改了什么、为什么、影响了哪些网络。
7. **贴出证据。** 以 `pcb_run_drc`、`design_lint_report`、
   `obj_crossref_net` 收尾，并附上它们的真实输出。没有输出的"检查通过"
   不算检查。
8. **有 DRC 违规就是没做完。** 看起来无害的也要逐条列出并说明处置方式，
   不得批量豁免。

## 10. 视觉复查补充条目

`design_visual_review` 自带一套 PCB 复查表 —— 离网格元件、锐角、外框
碰撞、镜像文字、板边间距、缺失去耦。在同一个回路里再走一遍下面这些条目，
并用所列审计工具交叉验证：

| 观察 | 交叉验证 |
|---|---|
| 同类元件未对齐，或组内间距不统一 | 目视 |
| 块内极性器件朝向不一致 | 目视 |
| 位号旋转到 0°/90° 以外的角度 | `audit_find_mirrored_pcb_text` |
| 有铺铜但未在面上缝合 | `pcb_get_vias` |
| 走线跨越平面分割或平面缺口 | 目视，再查参考层 |
| 重新铺铜后的孤岛铜或铜尖 | `pcb_run_drc` |
| 全板密度明显不均 | 目视 |
| 丝印不可读、有歧义，或缺 1 脚 / 极性标记 | `audit_find_designator_collisions` |
